# OpenStreetMap в QORGO

- Flutter: `feature/maps/map_view.dart`, библиотека `flutter_map` 8.3.2.
- «На карте» открывает текущую полученную геопозицию в приложении.
- «Место SOS» открывает координаты входящей или сохранённой тревоги.
- Маркер показывает точку, круг — точность GPS; координаты и время сохраняются
  видимыми при ошибке загрузки карты. Открытие карты не запускает геолокацию.
- Backend и SMS приложения формируют ссылки OSM с маркером, включая нулевые и
  отрицательные координаты. Сохранённые исторические ссылки не переписываются.
- На лендинге используется lazy-loaded OSM embed с демонстрационной точкой Оша.
  Это иллюстрация, а не местоположение пользователя или работающий сигнал SOS.

## Настройка

`QORGO_MAP_TILE_URL` через `--dart-define` меняет URL тайлов.
По умолчанию `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
`QORGO_MAP_ATTRIBUTION` меняет подпись; при смене провайдера укажите его атрибуцию.
Обязательная подпись OpenStreetMap остаётся видимой и ведёт на copyright page.
API-ключ для стандартных публичных тайлов не требуется.

Native User-Agent идентифицирует приложение `kg.qorgo.qorgo`. Веб-запросы отправляют
Referer браузера; referrer policy лендинга сохраняет origin. Flutter кеширует тайлы
по HTTP-заголовкам через встроенный NetworkTileProvider. Предзагрузка регионов и
офлайн-скачивание отсутствуют; запросы выполняются при открытой карте.

Публичные серверы OSM работают без SLA и могут ограничивать нагрузку. Для
массового использования выберите провайдера с нужными лимитами и условиями:
https://operations.osmfoundation.org/policies/tiles/.

Карты не строят маршруты и не определяют «безопасность» улиц. Геолокация по-прежнему
поступает с устройства или из уже сохранённого SOS; OSM отображает базовую карту.
