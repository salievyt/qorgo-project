# Дизайн мобильного QORGO

Источник визуальных решений — `landing/src/styles.css` и `landing/public/brand/`.

Общая тема Flutter: `mobile/lib/core/design/qorgo_theme.dart`.

| Элемент | Значение сайта и приложения |
| --- | --- |
| Шрифт | Onest, локальные Latin/Cyrillic наборы |
| Основной текст | #080B09 |
| Вторичный текст | #5E6470 |
| Зелёный акцент | #235D3B |
| Фон | #EEF0F4 |
| Светлая поверхность | #F6F7F9 |
| Карточки | Белые, радиус 24 px |
| Кнопки и поля | Радиус 12 px |
| Высота основной кнопки | 52 px |
| SOS / ошибка | #D34C43 |

Логотип берётся из того же SVG, что и шапка сайта. Шрифты преобразованы из исходных WOFF2 сайта в TTF для Flutter без изменения рисунка глифов; лицензия OFL сохранена рядом и включена в assets.

Мобильные размеры заголовков и отступов адаптированы к экрану телефона. Карточки, формы, навигация, диалоги и карта используют общие цвета. SOS сохраняет полный жест вправо и заметный красный цвет. Сетевые запросы, авторизация и правила отправки не менялись.
