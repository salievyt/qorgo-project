# Дизайн мобильного QORGO

Источник визуальных решений — `landing/src/styles.css` и `landing/public/brand/`.

Общая тема Flutter: `mobile/lib/core/design/qorgo_theme.dart`.

| Элемент | Значение сайта и приложения |
| --- | --- |
| Шрифт | Onest, локальные Latin/Cyrillic наборы |
| Основной текст | #F2F7F3 |
| Вторичный текст | #8CAA97 |
| Зелёный акцент | #235D3B |
| Фон приложения | #030705 (тёмный макет телефона на сайте) |
| Поверхность карточек | #111513 |
| Карточки | Тёмные, радиус 24 px |
| Кнопки и поля | Радиус 12 px |
| Высота основной кнопки | 52 px |
| SOS / ошибка | #D34C43 |

Светлый логотип берётся из того же SVG, что и тёмный макет телефона на сайте. Шрифты преобразованы из исходных WOFF2 сайта в TTF для Flutter без изменения рисунка глифов; лицензия OFL сохранена рядом и включена в assets.

Мобильные размеры заголовков и отступов адаптированы к экрану телефона. Карточки, формы, навигация, диалоги и карта используют общие цвета. SOS сохраняет полный жест вправо и заметный красный цвет. Сетевые запросы, авторизация и правила отправки не менялись.


## Нижняя навигация и запуск

`core/widgets/bottom_nav_bar.dart`: стандартная закреплённая панель на всю ширину с четырьмя разделами. Подписи видны всегда; у активного раздела зелёный цвет и заполненная иконка. Панель учитывает системную область жестов, а содержимое располагается выше неё.

`feature/app/splash_view.dart`: логотип, круги радара из макета сайта и короткое появление. Splash ждёт завершения восстановления сессии и показывается минимум 1,2 секунды. При отключённых системных анимациях появление мгновенное. iOS LaunchScreen и Android LaunchTheme показывают тёмный фон и логотип ещё до первого кадра Flutter, включая Android 12+.


## Иерархия главной

Компактное приветствие → один основной блок SOS → компактный обзор близких и местоположения. Для пустого круга первичное действие — добавить первого близкого; после добавления в том же блоке появляется SOS-слайдер. Активная тревога и входящие сигналы имеют приоритет перед обычным обзором. Технические координаты доступны на карте, время синхронизации не занимает главную. Основной заголовок 28 px, приветствие 14 px, строки обзора 15/12 px.
