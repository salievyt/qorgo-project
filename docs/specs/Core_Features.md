# Основные функции QORGO

Подтверждены пользователем 11 октября 2026 года. Это обязательный состав продукта; подтверждение требований не означает завершение реализации.

1. Кнопка SOS: передача координат и данных профиля для вызова охранного партнёра в зоне обслуживания. Полный свайп согласно SOS_Slider.md. Цель прибытия 3–7 минут должна подтверждаться договорами и пилотом; утверждение «быстрее не приедет никто» не используется без доказательств.
2. Локация близких: местоположение в реальном времени с согласия участника.
3. Мониторинг близких: уведомления о прибытии в выбранную геозону и выходе из неё.
4. Fake Call: виртуальный входящий звонок для выхода из неловкой ситуации. Это имитация звонка, не связь с реальным человеком.

Базовая цифровая версия и тариф с реагированием разделены. Выезд охраны подключается в отдельном тарифе после согласования партнёра, покрытия и стоимости. Текущий MVP уже поддерживает SOS близким; охранное реагирование, живая семейная локация, геозоны и Fake Call предстоит реализовать.

Облачное хранение аудио/видео исключено из тарифов по указанию пользователя.
