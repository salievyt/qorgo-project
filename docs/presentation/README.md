# Презентация QORGO

[QORGO_Presentation.pptx](QORGO_Presentation.pptx) — 11 редактируемых слайдов, 16:9, на русском языке. Оформление соответствует лендингу: светлый фон, зелёные акценты и актуальный логотип.

Содержание: идея проекта, Personal, сценарий SOS, терминалы X, Control, предложение пилота в Оше, предварительный бюджет, данные и следующие шаги.

Состояние материалов: 11 октября 2026 года. Предложения пилота и бюджета не утверждены. Источники указаны в заметках слайдов.

Копия для скачивания с сайта: `landing/public/QORGO_Presentation.pptx`. При обновлении презентации необходимо обновлять обе копии.
