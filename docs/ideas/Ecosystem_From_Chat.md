# 3. Экосистема QORGO — безопасность

Это одно из наиболее масштабных направлений среди твоих идей.

### 7. QORGO
**Прежнее название:** Gardy.me  
**Категория:** SafetyTech, Personal Security, IoT  
**Статус:** Проработка продукта и архитектуры

QORGO — система безопасности человека и его близких.

Основная идея: создать технологическую платформу, позволяющую быстрее реагировать на опасные ситуации.

**Основные функции:**
- Экстренная кнопка SOS.
- Геолокация в реальном времени.
- Семейные группы.
- Уведомления близких.
- Обнаружение падений.
- Контроль пульса.
- Геозоны.
- История местоположений.
- Экстренные уведомления.

Дополнительно ты рассматривал умный браслет QORGO.

Браслет должен взаимодействовать с приложением и передавать сигналы об экстренных ситуациях.

**Техническая основа:** Flutter и Django Backend.

### 8. QORGO Vision
**Категория:** Computer Vision, Public Safety  
**Статус:** Концепция, сформировано первоначальное ТЗ

Недавно, 7 октября 2026 года, мы обсуждали новое направление QORGO.

Ты предложил создать специализированную систему поиска транспортных средств и людей для уполномоченных государственных структур Кыргызстана.

По концепции она должна работать с разрешёнными источниками видеонаблюдения.

**Первый этап:**
- Подключение камер.
- Распознавание автомобильных номеров.
- Поиск автомобилей.
- История обнаружений.
- Отображение событий на карте.
- Просмотр кадров.
- Хронология перемещений.

**Последующие направления:**
- Аналитика видеопотоков.
- Поиск людей при наличии законных оснований и разрешений.
- Ситуационный мониторинг.
- Система уведомлений.
- Контроль доступа и аудит действий.

Проект требует отдельной правовой оценки, строгой защиты персональных данных и согласованных механизмов доступа.

### 9. QORGO Command
**Категория:** Security Operations, Monitoring  
**Статус:** Концепция

Предполагаемый ситуационный центр экосистемы QORGO.

Идея — объединить информацию из различных модулей безопасности в одном интерфейсе.

**Предполагаемые функции:**
- Мониторинг событий.
- Карта происшествий.
- Управление инцидентами.
- Уведомления.
- Аналитические панели.
- Координация реагирования.

В перспективе ты рассматриваешь три направления:

**QORGO Personal → QORGO Vision → QORGO Command**

Вместе они могут сформировать QORGO Safety Platform.
