# QORGO Mobile MVP

Flutter для Android и iOS. Clean Architecture + MVVM: `core`, `domain`, `data`, `feature`. Данные сохраняются на Django/PostgreSQL, токен — в защищённом хранилище устройства.

Рабочий минимум: регистрация и вход, профиль, доверенные контакты, SOS с координатами для близких и диспетчерской, входящие сигналы от близких, подтверждение помощи, завершение тревоги и история. Пользователь отдельно включает или выключает показ текущей геопозиции оператору в настройке непрерывной защиты. Приложение по умолчанию подключено к `https://api.qorgo.services/api`.

## Запуск

```sh
flutter pub get
flutter run -d <iOS-device-id>
```

На этом Mac Flutter: `/Users/sm1le/develop/flutter/bin/flutter`.
iOS-симулятор Xcode 27: `/Applications/Xcode.app/Contents/Applications/DeviceHub.app`.

Для локального API можно переопределить адрес:

```sh
flutter run --dart-define=QORGO_API_URL=http://127.0.0.1:8000/api
```

Для передачи SOS зарегистрируйте два аккаунта. Отправитель добавляет контакт с email второго аккаунта. Оба открывают QORGO; полный жест SOS создаёт входящий сигнал у близкого. «Помогаю» меняет статус у отправителя. Обновление происходит каждые 5 секунд и при возвращении в приложение. Не требуется запускать локальный сервер или SMS-провайдер.

В закрытом приложении push пока не приходит. Кнопки SMS и звонка открывают системные приложения; телефонные функции проверяются на физическом телефоне. Таймер и тарифы сохранены в исходниках, но скрыты из минимального интерфейса.

### OpenStreetMap

Встроенная карта открывается из «Моё местоположение», входящих SOS и истории
тревог. Маркер показывает полученные координаты, круг — точность GPS; дата и
время помогают отличить старую точку от текущей. Открытие карты не запрашивает
геолокацию повторно. Ссылки в SOS/SMS ведут на OpenStreetMap с той же точкой.

Используется `flutter_map` с встроенным кешированием по HTTP-заголовкам,
HTTPS-тайлами, идентификатором `kg.qorgo.qorgo` и видимой атрибуцией.
Провайдер меняется через `--dart-define=QORGO_MAP_TILE_URL=...`, подпись — через
`QORGO_MAP_ATTRIBUTION`. Для другого провайдера добавьте его атрибуцию.
Публичные тайлы OSM используются только для просмотра открытой карты;
загрузка регионов для офлайн-работы не реализована.
Политика: https://operations.osmfoundation.org/policies/tiles/.
