# QORGO

Материалы стартапа QORGO by DEO-CORE. Собраны 11 октября 2026 года.

QORGO — концепция платформы личной, семейной и общественной безопасности: приложение, носимые устройства, SOS-терминалы и инструменты координации реагирования.

- [Мобильное приложение Flutter](mobile/README.md) — рабочая основа MVP для Android и iOS.
