## SEO

Полный HTML генерируется при сборке, интерактивность React подключается через hydration. В HTML есть один H1, связанная структура заголовков, актуальные title и description, canonical `https://www.qorgo.services/`, Open Graph, Twitter Card, JSON-LD Organization / WebSite / WebPage. Добавлены robots.txt и sitemap.xml, preconnect к шрифтам, долговременный кеш хешированных ресурсов. Подписки и партнёрства не выданы в разметке за запущенные коммерческие услуги.

## Google Search Console

Создан и подтверждён Domain property `qorgo.services`, охватывающий корневой домен и субдомены. Отправлена карта `https://www.qorgo.services/sitemap.xml`. Живая проверка главной: «URL доступен Google», «Эту страницу можно проиндексировать». Запрос на индексирование принят: URL добавлен в приоритетную очередь сканирования.

Карта сайта отправлена и доступна по HTTPS с ответом 200, но отчёт Sitemap в последней проверке ещё показывал «Не получено» / «Не удалось обработать». После выпуска сертификатов карта отправлена повторно. Дополнительная живая проверка самого `/sitemap.xml` в Google подтвердила «URL доступен Google» — загрузка работает. Требуется дождаться обработки отчёта Google. Это не препятствует уже принятому запросу индексирования главной.

Индексирование и первое место не гарантируются. После обработки Google нужно оценивать реальные поисковые запросы, показы, клики и Core Web Vitals. У нового ресурса отчёты пока собираются; собственная публикация не означает, что URL уже присутствует в поисковом индексе.

## Обновления

`npm run build` собирает клиент и предварительно генерирует HTML. Vercel выполняет эту сборку при публикации изменений в `main`. Общий каталог тарифов импортируется из `mobile/assets/tariffs.json`, поэтому сборке нужен доступ к файлам за пределами Root Directory. Публикуется только `landing/dist`.
