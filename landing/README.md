# QORGO — React-лендинг

Серьёзный презентационный сайт проекта QORGO. React + Vite, адаптивная вёрстка, раскрывающиеся вопросы, закреплённая навигация, локальная демонстрация SOS-ползунка, скачиваемое описание проекта.

## Запуск

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Готовые статические файлы появляются в `dist/`. Публикация не настроена.

## Файлы

- `src/main.jsx` — разделы страницы и интерактивная демонстрация.
- `src/styles.css` — оформление и адаптивность.
- `public/brand/qorgo.svg` — предоставленный логотип; `qorgo-dark.svg` — вариант для светлого фона.
- `public/QORGO_Project_Brief.txt` — скачиваемое описание.

Демонстрация SOS не обращается к серверу, не получает геолокацию и не вызывает экстренные службы. Представленные функции обозначены как концепция. Контактная форма не добавлена, поскольку подтверждённый контакт для сотрудничества не предоставлен. Шрифт Onest загружается из Google Fonts; при недоступности используется Arial.

## Дизайн

Композиция и визуальная система переработаны по референсу https://gardy.me/md/ru: светло-серый фон, округлённые белые блоки, зелёные CTA, типографика Onest, телефон на первом экране, лента ситуаций, карточки функций и нумерованный FAQ. Тексты и графика созданы для QORGO. Фотографии, отзывы, статистика пользователей, тарифы и обещания времени реагирования Gardy не переносились.

Актуальный знак QORGO основан на SVG-примере пользователя «Графичесткий символ пример.svg»: геометрический контур с буквой Q. Предыдущий вариант с человеком сохранён в `public/brand/archive/person-symbol/`.

Текущий логотип: новые `QORGO.svg` и `QORGO.png`, предоставленные пользователем. Форма сохранена. Для сайта подготовлены белая, тёмная и зелёная версии с обрезкой пустых полей SVG.
